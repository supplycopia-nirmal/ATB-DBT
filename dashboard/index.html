Dataset Transformations & Data Dictionary

1. How the Transformed Dataset is Generated

The final Transformed Dataset (fct_cost_savings_analysis) integrates all 4 raw data sources (Consumption, Item Master, Purchase Orders, Invoices). It computes accurate cost savings by joining on items and tracing the full lineage of a product from its contract price through to consumption. All original source columns are preserved, and new columns are added to enrich the data for analytics.

2. AI-Powered DRG Mapping (Consumption)

We used GPT-5.6-Luna to resolve ambiguous DRG Codes in the consumption data.
✨ primary_drg_code: Extracted single correct DRG code based on the procedure.
✨ primary_procedure_group: LLM-classified procedure category (e.g. Cardiovascular).

3. Item Master Data Quality


✨ is_missing_vendor_code / is_missing_mfr_name: Flags for missing critical identifiers.
✨ custom_category: Fallback categorization logic for unclassified items.
✨ data_quality_score: A 0-100 score indicating the completeness of the item profile.

Cost Savings Calculations

These calculations apply to the V1 table (which aggregates all data sources) and the V2 tables (which are isolated to Purchase Orders and Consumption separately).

Price Variance

price_variance = (actual_unit_price - contract_price) * total_quantity

Calculates the difference between the actual unit price paid (from Consumption or POs) and the matched historic contract unit price, multiplied by the quantity.

Total Identified Savings

Total Savings = SUM(price_variance) WHERE price_variance > 0

Aggregates all positive price variances across records to identify the total systemic cost savings opportunity.
